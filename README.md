# projekt.net_IKS_zofia_stanislawska
Projekt na zajęcia .NET - Aplikacja do randkowania dla ryb

Fisht - Love at First Sight

Aplikacja randkowa dla ryb co pozwala na znajdowaniu sobie partnerów/partnerek o tych samych warunkach do życia (woda morska/rzeczna, ciepła/zimna) oraz podobnych zainteresowaniach (hobby itp.). 

By użytkownik mógł korzystać z aplikacji wpierw będzie musiał się zalogować bądź utworzyć konto. Ryby będą mogły dodawać zdjęcia na profil oraz na profilowe, tworzyć posty, oraz czatować ze sobą po wzajemnym polubieniu się na profilu.

Moderator będzie mógł banować oraz usuwać nieprzyzwoite zdjęcia i profile użytkowników.
